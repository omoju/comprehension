# Chapter 1 · The World the Dict Enters

> **Enters as:** `secret_key='secret key'`, `salt='auth'`, `serializer=None`, `serializer_kwargs=None`, `signer=None`, `signer_kwargs=None`, `fallback_signers=None`

The dict `{"id": 5, "name": "itsdangerous"}` does not exist yet. Before it can be handed out to a URL, a cookie, or an email link, someone has to build the machine that will vouch for it — and that machine is built in one constructor call, out of two short strings.

`URLSafeSerializer("secret key", "auth")` is a thin class: it declares no code of its own, only a combination of a mixin and a base ([url_safe.py](https://github.com/pallets/itsdangerous/blob/672971d66a2ef9f85151e53283113f33d642dabd/src/itsdangerous/url_safe.py#L72-L76)). So the two strings land in `Serializer.__init__` ([serializer.py](https://github.com/pallets/itsdangerous/blob/672971d66a2ef9f85151e53283113f33d642dabd/src/itsdangerous/serializer.py#L190-L202)), with every other parameter left as `None` for the defaults to fill in.

**The key becomes a list.** `'secret key'` goes first to `_make_keys_list`, which sees a `str`, wraps it, and returns `[b'secret key']` ([signer.py](https://github.com/pallets/itsdangerous/blob/672971d66a2ef9f85151e53283113f33d642dabd/src/itsdangerous/signer.py#L67-L73)). The encoding step is `want_bytes`, which encodes text as UTF-8 with `errors='strict'` ([encoding.py](https://github.com/pallets/itsdangerous/blob/672971d66a2ef9f85151e53283113f33d642dabd/src/itsdangerous/encoding.py#L11-L17)) — so from here on a key is bytes, and comparisons never depend on how someone typed the string. The list shape matters to you as an owner: it is the key-rotation seam. Pass any other iterable and you get a list of keys, oldest to newest, stored as `self.secret_keys` ([serializer.py](https://github.com/pallets/itsdangerous/blob/672971d66a2ef9f85151e53283113f33d642dabd/src/itsdangerous/serializer.py#L208)). One key today, several during a rotation window, and the code path is identical.

**The salt becomes bytes and nothing more.** `'auth'` is run through `want_bytes` and stored as `b'auth'` ([serializer.py](https://github.com/pallets/itsdangerous/blob/672971d66a2ef9f85151e53283113f33d642dabd/src/itsdangerous/serializer.py#L210-L214)). Had the caller passed `None`, the salt would be left unset here and the `Signer`'s own default would apply later — the comment on line 212 says exactly that. The salt's default when omitted entirely is `b"itsdangerous"` ([serializer.py](https://github.com/pallets/itsdangerous/blob/672971d66a2ef9f85151e53283113f33d642dabd/src/itsdangerous/serializer.py#L193)). Worth being clear with anyone reviewing this: the salt is *not* a secret. It separates contexts — an "auth" token must not be replayable as an "upgrade" token — and it is fine in source control. The secret key is the thing that must not be.

**The serializer is chosen, then probed.** No `serializer` was passed, so the class attribute is used ([serializer.py](https://github.com/pallets/itsdangerous/blob/672971d66a2ef9f85151e53283113f33d642dabd/src/itsdangerous/serializer.py#L216-L219)). For a plain `Serializer` that would be stdlib `json` ([serializer.py](https://github.com/pallets/itsdangerous/blob/672971d66a2ef9f85151e53283113f33d642dabd/src/itsdangerous/serializer.py#L95)), but `URLSafeSerializerMixin` overrides it with `_CompactJSON` ([url_safe.py](https://github.com/pallets/itsdangerous/blob/672971d66a2ef9f85151e53283113f33d642dabd/src/itsdangerous/url_safe.py#L21)) — the same `json`, with `separators=(",", ":")` and `ensure_ascii=False` ([_json.py](https://github.com/pallets/itsdangerous/blob/672971d66a2ef9f85151e53283113f33d642dabd/src/itsdangerous/_json.py#L14-L18)). Shorter tokens, which matters when they ride in a URL.

Then something slightly unusual happens, and it is the only real work in this constructor: `is_text_serializer` calls `serializer.dumps({})` and checks whether the result is a `str` ([serializer.py](https://github.com/pallets/itsdangerous/blob/672971d66a2ef9f85151e53283113f33d642dabd/src/itsdangerous/serializer.py#L33-L37)). In the trace you can see the throwaway call return `'{}'`, and `is_text_serializer` return `True`, which is cached on the instance ([serializer.py](https://github.com/pallets/itsdangerous/blob/672971d66a2ef9f85151e53283113f33d642dabd/src/itsdangerous/serializer.py#L220)). This is a probe, not a declaration. It's cheap and it's right for `json` and `pickle` alike — but note the failure mode: a custom serializer that can't handle `{}`, or that is expensive to call, pays for it at construction time, and the error surfaces from a constructor rather than from `dumps`.

**The signer is chosen, and not used.** `signer=None` means the class default, which for this class is the plain `Signer` ([serializer.py](https://github.com/pallets/itsdangerous/blob/672971d66a2ef9f85151e53283113f33d642dabd/src/itsdangerous/serializer.py#L222-L226) and [L99](https://github.com/pallets/itsdangerous/blob/672971d66a2ef9f85151e53283113f33d642dabd/src/itsdangerous/serializer.py#L99)). Only the *class* is stored, plus an empty `signer_kwargs`; no signer object is built and no hashing happens yet. That is deliberate: `hashlib.sha1` is reached only through `_lazy_sha1`, so that FIPS builds without SHA-1 can be reconfigured before anything touches it ([signer.py](https://github.com/pallets/itsdangerous/blob/672971d66a2ef9f85151e53283113f33d642dabd/src/itsdangerous/signer.py#L40-L45)).

**The fallbacks are empty, by design.** `fallback_signers=None` copies the class default ([serializer.py](https://github.com/pallets/itsdangerous/blob/672971d66a2ef9f85151e53283113f33d642dabd/src/itsdangerous/serializer.py#L228-L233)), and that default is the empty list ([serializer.py](https://github.com/pallets/itsdangerous/blob/672971d66a2ef9f85151e53283113f33d642dabd/src/itsdangerous/serializer.py#L102-L104)). It was not always: a SHA-512 fallback shipped in 1.1 and was removed in 2.0. So out of the box, exactly one set of signing parameters will be accepted on the way back. `serializer_kwargs` is likewise an empty dict ([serializer.py](https://github.com/pallets/itsdangerous/blob/672971d66a2ef9f85151e53283113f33d642dabd/src/itsdangerous/serializer.py#L234)) — remember it, because whatever goes in there ends up shaping the bytes that get signed.

And that is the whole world: a list with one key in it, a salt as bytes, a compact JSON module, a boolean remembered from a test call, a signer class held in reserve, and two empty containers. Nothing has been signed. The dict is next.
