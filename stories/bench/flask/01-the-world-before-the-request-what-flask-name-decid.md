# Chapter 1 · The World Before the Request: What `Flask(__name__)` Decides For You

> **Enters as:** `import_name='__main__'`, with every other constructor argument left at its default (`static_url_path=None`, `static_folder='static'`, `static_host=None`, `host_matching=False`, `subdomain_matching=False`, `template_folder='templates'`, `instance_path=None`, `instance_relative_config=False`, `root_path=None`).

No request exists yet. What exists is a single string, `'__main__'`, handed to [`Flask.__init__`](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/app.py#L311-L323). Everything an incoming `GET /` will later be measured against — which routes exist, whether sessions work, whether debug tracebacks leak, which hosts are trusted — is decided in the next fifty-odd trace lines, from that one string plus a pile of defaults nobody typed.

`Flask.__init__` immediately passes the whole argument list up to [`App.__init__`](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/app.py#L324-L335), which passes a subset further up to [`Scaffold.__init__`](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/sansio/scaffold.py#L75-L100) — the layer shared with `Blueprint`. There, `'static'` goes through the [static folder setter](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/sansio/scaffold.py#L233-L238), which strips trailing slashes and stores it; `static_url_path=None` goes through [its setter](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/sansio/scaffold.py#L264-L269) and stays `None`, to be derived later.

Then the import name earns its keep. `root_path` was `None`, so [`get_root_path('__main__')`](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/helpers.py#L587-L600) looks the module up in `sys.modules`, finds it has a `__file__`, and returns that file's directory — in this run `'stories/bench/flask'`. Templates, static files, and `open_resource` will all be resolved relative to that path. Scaffold also lays out the empty registries the request will consult later: `view_functions`, the nested [`error_handler_spec`](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/sansio/scaffold.py#L123-L126) defaultdict, and the `before_request_funcs` / `after_request_funcs` / `teardown_request_funcs` dicts. In this app they stay empty, which is why later chapters will have so few hooks to run.

Back in `App.__init__`, [`auto_find_instance_path`](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/sansio/app.py#L507-L518) asks [`find_package('__main__')`](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/sansio/scaffold.py#L762-L800) where this code lives; it answers `(None, 'demo-repos/flask')` — prefix `None` meaning "not installed" — so the instance path becomes that directory plus `instance`. Nothing is created on disk; it is just a path the app will offer if asked.

## The config: twenty-nine decisions you did not make

[`make_config`](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/sansio/app.py#L479-L493) copies [`Flask.default_config`](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/app.py#L207-L239) — twenty-nine keys — and then does one thing that is not a copy: it overwrites `DEBUG` with [`get_debug_flag()`](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/helpers.py#L28-L33), which reads the `FLASK_DEBUG` environment variable. In this run it returned `False` (trace lines 19–20). The declared default in the class body is `None`; the effective default is whatever the environment says.

The resulting [`Config`](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/config.py#L94-L100) is a plain `dict` subclass that also remembers `root_path` for later file loading. Three of its values will decide most of what happens in this story: `SECRET_KEY: None`, `TRUSTED_HOSTS: None`, `PROPAGATE_EXCEPTIONS: None`.

> **For the owner:** `SECRET_KEY` defaults to `None` and app construction succeeds anyway, with no warning. Sessions in this app are therefore non-functional in a specific way you will see in Chapter 4. Confirm that any app you sign off on sets `SECRET_KEY` from configuration before it serves traffic.

> **For the owner:** `DEBUG` comes from the `FLASK_DEBUG` environment variable at construction time, not from code. Verify that your production environment does not set `FLASK_DEBUG`, because that single variable switches on tracebacks in responses and exception re-raising.

Two small objects follow: [`make_aborter`](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/sansio/app.py#L495-L505) builds the `Aborter` that `flask.abort` will call, and the JSON provider is constructed, storing the app as a [`weakref.proxy`](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/json/provider.py#L38-L39) so the provider does not keep the app alive. Then the [`url_map`](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/sansio/app.py#L402-L408) is created with `host_matching=False`, `subdomain_matching` is stored as `False`, and `_got_first_request` is set to `False` — a flag that will matter a great deal in Chapter 5.

## Two routes get written into the map

Back in `Flask.__init__`, the app gets a Click group named after itself, and then the static route. [`has_static_folder`](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/sansio/scaffold.py#L240-L246) is `True` because `static_folder` resolves to `<root_path>/static`, and [`static_url_path`](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/sansio/scaffold.py#L248-L262) derives `'/static'` from that folder's basename. The route is then registered [without checking whether the directory exists](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/app.py#L352-L364) — deliberately, since the folder may appear later — and the view function is a lambda closing over a `weakref.ref(self)` rather than the app itself, to avoid a reference cycle between app and view.

> **For the owner:** A `/static/<path:filename>` route is added to every app that has a static folder configured, existing or not, and it serves files off the filesystem. If your deployment serves static assets from a reverse proxy, pass `static_folder=None` so the application does not also expose that path.

Both registrations — the static one and the user's `@app.route("/")` — go through [`setupmethod`](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/sansio/scaffold.py#L42-L49), which calls [`_check_setup_finished`](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/sansio/app.py#L410-L420) first. While `_got_first_request` is `False` the check returns silently (trace lines 38–40, 52–54); it is a lock that has not yet engaged.

Inside [`add_url_rule`](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/sansio/app.py#L604-L661), the decorated function supplies the endpoint name: for the static route it was given explicitly; for `hello` the trace shows [`_endpoint_from_view_func`](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/sansio/scaffold.py#L709-L714) returning `'hello'` — the function's `__name__`. [Methods default to `("GET",)`](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/sansio/app.py#L616-L628), and because `PROVIDE_AUTOMATIC_OPTIONS` is `True` and `OPTIONS` was not declared, [`OPTIONS` is added to the rule and `provide_automatic_options=True` is stamped onto the rule object](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/sansio/app.py#L633-L651). That flag is a message to Chapter 6: an `OPTIONS` request to `/` will never reach the view. Finally the rule is added to the map and the view is recorded in `view_functions`, with [an `AssertionError` if an endpoint name is reused for a different function](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/sansio/app.py#L653-L661) — a collision fails at import, not at request time.

The decorator [returns the original function unchanged](https://github.com/pallets/flask/blob/d73fa1cdcbd8b1465c151db8924ba58b1dd14e35/src/flask/sansio/scaffold.py#L368-L371), so `hello` is still an ordinary callable; the registration happened as a side effect. The world is now built, and nothing has been served.

> **Leaves as:** A `Flask` instance carrying a `Config` of 29 defaults (`DEBUG=False`, `SECRET_KEY=None`, `TESTING=False`, `PROPAGATE_EXCEPTIONS=None`, `TRUSTED_HOSTS=None`, `PROVIDE_AUTOMATIC_OPTIONS=True`, …), a `url_map` holding two rules — `/static/<path:filename>` → `static` and `/` → `hello` with methods `{GET, HEAD, OPTIONS}` and `provide_automatic_options=True` — empty hook registries, and `_got_first_request = False`.
