# Chapter 2 · Asked For By Name

> **Enters as:** `Environment.get_template(name='members.html', parent=None, globals=None)` — the source still sitting untouched in the loader's mapping

Nobody hands Jinja the template. They hand it a name.

That is the first thing to notice about this chapter: the string `'members.html'` is the only thing the caller supplies, and everything that follows — which text gets read, which text gets compiled, which text ends up in the browser — is decided by looking that name up. `get_template` checks two things before it commits. If `name` were already a `Template` object it would be returned unchanged, and if `parent` were not `None` the name would first be run through `join_path`. Here `name` is a plain string and `parent` is `None`, so both branches are skipped and the name goes straight through to `_load_template` ([environment.py#L1010-L1015](https://github.com/pallets/jinja/blob/5ef70112a1ff19c05324ff889dd30405b1002044/src/jinja2/environment.py#L1010-L1015)). No normalisation, no prefix, no check of its own.

> **For the owner:** The template name is the entire access decision; `get_template` itself does not validate it. Whether a name can escape the intended template set depends only on the loader behind it — `DictLoader` is a dict lookup ([loaders.py#L444-L450](https://github.com/pallets/jinja/blob/5ef70112a1ff19c05324ff889dd30405b1002044/src/jinja2/loaders.py#L444-L450)), while `FileSystemLoader` and `PackageLoader` route the name through `split_template_path`, which raises `TemplateNotFound` on any `..` segment ([loaders.py#L25-L39](https://github.com/pallets/jinja/blob/5ef70112a1ff19c05324ff889dd30405b1002044/src/jinja2/loaders.py#L25-L39)). Trace every path where a template name can be influenced by request data and confirm the loader on that path rejects traversal.

Inside `_load_template` the first move is to ask whether this work has been done before. The cache key is built as `(weakref.ref(self.loader), name)` ([environment.py#L961](https://github.com/pallets/jinja/blob/5ef70112a1ff19c05324ff889dd30405b1002044/src/jinja2/environment.py#L961)) — not the name alone. Two loaders in the same environment cannot collide on a shared name, and because the key holds a *weak* reference, a cached entry stops being reachable once its loader is garbage collected. The trace shows the key as `(<weakref at 0x10a5edf80; to 'jinja2.loaders.DictLoader' at 0x10969d550>, 'members.html')`, and the LRU cache answers `None`. Cold start. Nothing to reuse.

Had there been a hit, the code would still not have trusted it blindly: with `auto_reload` left at its default `True`, a cached template is only returned if `template.is_up_to_date` agrees ([environment.py#L962-L972](https://github.com/pallets/jinja/blob/5ef70112a1ff19c05324ff889dd30405b1002044/src/jinja2/environment.py#L962-L972)). That road is not taken today, but it is the road the *second* call will take, and the thing it consults is manufactured a few lines from now.

So the environment builds the globals the template will be born with. `make_globals(None)` turns the absent dict into an empty one and returns `ChainMap(d, self.globals)` ([environment.py#L1127-L1130](https://github.com/pallets/jinja/blob/5ef70112a1ff19c05324ff889dd30405b1002044/src/jinja2/environment.py#L1127-L1130)). The trace records exactly that: `ChainMap({}, {'range': <class 'range'>…})`. The shape is deliberate — anything written into a template's globals lands in the empty first map and can never reach the environment's shared dict, while later additions to the environment's globals are still visible through the second. A mutable default is contained by construction rather than by discipline.

Now the string itself finally moves. `BaseLoader.load` is called with the environment, the name, and that ChainMap, and the very first thing it does is ask for the source ([loaders.py#L126](https://github.com/pallets/jinja/blob/5ef70112a1ff19c05324ff889dd30405b1002044/src/jinja2/loaders.py#L126)). `DictLoader.get_source` finds `'members.html'` in the mapping and returns a three-tuple: the source text, `None` for the filename, and a lambda that closes over the source it just read ([loaders.py#L447-L450](https://github.com/pallets/jinja/blob/5ef70112a1ff19c05324ff889dd30405b1002044/src/jinja2/loaders.py#L447-L450)). Had the name been absent, this is where `TemplateNotFound(template)` would have been raised and the whole call would have ended.

That lambda is the staleness check: `lambda: source == self.mapping.get(template)`. It compares the text captured now against whatever the mapping holds at the moment it is asked. Because `DictLoader` never copied the caller's dict back in chapter 1, editing the mapping in place genuinely invalidates the cached template on the next lookup.

Back in `load`, the bytecode cache is consulted — `environment.bytecode_cache` is `None`, so the block is skipped entirely and `code` stays `None` ([loaders.py#L130-L137](https://github.com/pallets/jinja/blob/5ef70112a1ff19c05324ff889dd30405b1002044/src/jinja2/loaders.py#L130-L137)). With nothing cached anywhere, there is only one thing left to do with a string: compile it. `load` calls `environment.compile(source, name, filename)` ([loaders.py#L138](https://github.com/pallets/jinja/blob/5ef70112a1ff19c05324ff889dd30405b1002044/src/jinja2/loaders.py#L138)), passing the name along so the compiler knows what to call this thing, and the `None` filename along with it.

> **For the owner:** `DictLoader` supplies no filename, and `Environment.compile` substitutes the literal string `"<template>"` before handing the source to Python's `compile` ([environment.py#L766-L768](https://github.com/pallets/jinja/blob/5ef70112a1ff19c05324ff889dd30405b1002044/src/jinja2/environment.py#L766-L768)). Every traceback from these templates will name `<template>` rather than a path; if you need file paths in production errors, use a loader that returns one.

The string leaves this chapter unchanged in content and changed in status. It is no longer anonymous data in a dict: it has a name attached, a staleness test built for it, a globals map waiting for it, and a compiler expecting it.

What it does not yet have is anything in the cache. The question that will matter the second time anyone asks for this page — what makes the next `get_template('members.html')` cheap, and can that cheap answer ever be a stale one — has been set up here but not yet settled.

> **Leaves as:** the raw source `'{% extends "base.html" %}\n{% block t…'`, with `name='members.html'` and `filename=None`, handed to `Environment.compile`; alongside it an uptodate closure and `ChainMap({}, env.globals)` waiting for the result
