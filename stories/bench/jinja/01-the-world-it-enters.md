# Chapter 1 · The World It Enters

> **Enters as:** `mapping={'base.html': '<!DOCTYPE html>\n<html lang="en">…', 'members.html': '{% extends "base.html" %}\n{% block t…'}`, plus `autoescape=select_autoescape(['html', 'htm', 'xml'])`

The source of `members.html` begins as nothing more than a value in a dict. Twenty-odd lines of text with `{% extends "base.html" %}` on the first line, a title block, a content block, a loop. It is not yet a template. It is a string, and the first thing that happens to it is that somebody takes custody of it.

`DictLoader.__init__` does that, and it does almost nothing: it binds the mapping to `self.mapping` and returns ([loaders.py#L441-L442](https://github.com/pallets/jinja/blob/5ef70112a1ff19c05324ff889dd30405b1002044/src/jinja2/loaders.py#L441-L442)). No copy is made. The dict the caller built and the dict the loader will read from are the same object, and the source string sits inside it, unexamined. Nothing has looked at a single `{%` yet. That matters later: when the loader is asked for this template it hands back the string together with a closure that will compare the string against whatever `self.mapping` holds at that moment ([loaders.py#L444-L450](https://github.com/pallets/jinja/blob/5ef70112a1ff19c05324ff889dd30405b1002044/src/jinja2/loaders.py#L444-L450)) — the mapping is live, not a snapshot.

Then a second character is created before the string moves anywhere: `select_autoescape(['html', 'htm', 'xml'])` returns a function ([utils.py#L581](https://github.com/pallets/jinja/blob/5ef70112a1ff19c05324ff889dd30405b1002044/src/jinja2/utils.py#L581)). The trace shows what it was built with — `enabled_extensions=['html', 'htm', 'xml'], disabled_extensions=(), default_for_string=True, default=False`. It is a policy, not an answer. Nobody has asked it anything. It will be called with a template *name*, and it will decide, by file extension, whether that template's output should be HTML-escaped.

> **For the owner:** The escaping policy is keyed on the template's filename extension, and the `default` is `False`. A template named `report.txt`, `email`, or anything outside `html/htm/xml` renders **unescaped**, so untrusted data interpolated there is not protected. Confirm that every template that emits markup is named with one of the enabled extensions, or set `default=True` and list the exceptions instead.

Now the `Environment` is built, and the string's whole future is decided by arguments it never sees. Most of them are defaults.

`autoescape` is the interesting one. The constructor's own default for it is `False` ([environment.py#L313](https://github.com/pallets/jinja/blob/5ef70112a1ff19c05324ff889dd30405b1002044/src/jinja2/environment.py#L313)) — escaping in Jinja is opt-in, and here it has been opted into by handing in that callable, which is simply stored ([environment.py#L349](https://github.com/pallets/jinja/blob/5ef70112a1ff19c05324ff889dd30405b1002044/src/jinja2/environment.py#L349)). Stored, and not called. The call comes much later, when an `EvalContext` is created for a specific template name ([nodes.py#L76-L84](https://github.com/pallets/jinja/blob/5ef70112a1ff19c05324ff889dd30405b1002044/src/jinja2/nodes.py#L76-L84)).

`cache_size=400` goes to `create_cache`, which returns an `LRUCache(400)` ([environment.py#L83-L93](https://github.com/pallets/jinja/blob/5ef70112a1ff19c05324ff889dd30405b1002044/src/jinja2/environment.py#L83-L93)). Our string will eventually be compiled into Python and the result parked in there. The same function has two other behaviours worth knowing: `0` returns `None`, which disables template caching entirely and recompiles on every request, and a negative size returns a plain `dict`, which never evicts.

Alongside it, three more defaults land ([environment.py#L356-L360](https://github.com/pallets/jinja/blob/5ef70112a1ff19c05324ff889dd30405b1002044/src/jinja2/environment.py#L356-L360)): the loader, `auto_reload=True` — so a cached template will be re-checked against its uptodate function before being reused — and `bytecode_cache=None`, which means there is nowhere to stash compiled bytecode between processes. Every cache miss will pay for a full lex, parse, and compile in this process.

`load_extensions(self, ())` is called and returns `{}` ([environment.py#L109-L124](https://github.com/pallets/jinja/blob/5ef70112a1ff19c05324ff889dd30405b1002044/src/jinja2/environment.py#L109-L124), stored at [#L366](https://github.com/pallets/jinja/blob/5ef70112a1ff19c05324ff889dd30405b1002044/src/jinja2/environment.py#L366)). This is quietly load-bearing for the story that follows. With no extensions registered, nothing will get a chance to preprocess the source text before the lexer sees it, and nothing will rewrite the token stream — `preprocess` reduces over an empty list and returns the string unchanged ([environment.py#L654-L658](https://github.com/pallets/jinja/blob/5ef70112a1ff19c05324ff889dd30405b1002044/src/jinja2/environment.py#L654-L658)). What the dict holds is exactly what the lexer will read.

Finally `is_async = False` is set and the whole thing is handed to `_environment_config_check` ([environment.py#L368-L369](https://github.com/pallets/jinja/blob/5ef70112a1ff19c05324ff889dd30405b1002044/src/jinja2/environment.py#L368-L369)). That function verifies three invariants: that `undefined` is a subclass of `jinja2.Undefined`, that the block, variable and comment start strings differ from one another, and that `newline_sequence` is one of the three accepted values ([environment.py#L127-L142](https://github.com/pallets/jinja/blob/5ef70112a1ff19c05324ff889dd30405b1002044/src/jinja2/environment.py#L127-L142)). All three are `assert` statements.

> **For the owner:** The environment's sanity checks are `assert`s, so they are compiled out when Python runs with `-O`. A misconfigured environment that would normally fail loudly at construction — overlapping delimiters, a non-`Undefined` undefined class — will instead fail obscurely at lex or render time in an optimized deployment. Check whether your production start-up uses `-O` or `PYTHONOPTIMIZE`.

The environment returns. Nothing has been read, lexed, parsed, or escaped. The source of `members.html` is still a string in a dict, exactly as it was written — but the rules it will be judged by are now all fixed: who is allowed to fetch it, how long the result of compiling it will be kept, whether anyone may rewrite it on the way in, and the policy that will decide, when the time comes, whether an ampersand in a username is dangerous.

> **Leaves as:** a configured `Environment` — `loader=<DictLoader>`, `cache=LRUCache(400)` (empty), `extensions={}`, `is_async=False`, `auto_reload=True`, `bytecode_cache=None`, `autoescape=<function select_autoescape.<locals>.autoescape>` — with the two template sources still untouched inside the loader's mapping.
